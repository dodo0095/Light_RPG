# 功能規格

> 版本: v2.0 | Sprint 2 | 最後更新: 2026-11-12
> 來源：`proposal/sprint1-proposal.md` 第 2、9 節、`晨光之誓_企劃書.md` 第 2、3、5 節；Sprint 2 見文末「Sprint 2」章節的來源列
> 層級：🟡 規格。驗收標準以 product-manager 的 `.knowledge/acceptance-criteria.md` 為準（產出後本檔同步引用）；數值以 `.knowledge/decision-tables.md` 為準。

## 概述

Sprint 1 做核心打卡循環：選職業 → 自動帶入預設習慣 → 「今天」畫面打勾 → 金幣／經驗／屬性經驗／HP 回饋 → 換日時結算。不做戰鬥畫面、美術、音效、推播。

## 詳細規格

### F1 安裝與開啟（#1）

| 項目 | 規格 |
|------|------|
| 流程 | Safari 開 `https://rpg.starklab.tw/` →「分享」→「加入主畫面」→ 從主畫面全螢幕開啟 |
| 離線 | 安裝後飛航模式仍可開啟、打卡 |
| 更新 | 有新版本時顯示「有新版本，點此更新」；點了才更新 |
| 邊界 | 首次開啟就離線 → 無法安裝（正常行為）；未加入主畫面時提示「加入主畫面可降低資料被清除的機率」 |
| App 內建瀏覽器 | 從 LINE 等 App 的內建瀏覽器開啟時不支援 Service Worker（T3 實測），無法離線也無法正確安裝。偵測到 `!('serviceWorker' in navigator)` 時，顯示「請用 Safari 開啟」提示與複製網址按鈕（文案與樣式依 G1 設計稿） |
| 持久儲存 | 啟動時呼叫 `navigator.storage.persist()`；設定頁顯示是否已取得持久儲存（T3：LINE 內建瀏覽器回 false，主畫面 App 待觀察） |

### F2 開場選職業（#4）

| 項目 | 規格 |
|------|------|
| 觸發 | `settings.onboardingCompletedAt` 為空時顯示 |
| 選項 | 戰士／法師／僧侶／遊俠，顯示主屬性與預設習慣方向 |
| 結果 | 建立角色、帶入該職業套組的 Habits／Dailies／To-dos／獎勵，直接進「今天」 |
| 目標 | 從安裝到第一次打卡 ≤ 60 秒 |
| 邊界 | 選完不能在 S1 重選（轉職是第二版）；資料匯入會覆蓋整個角色 |

### F3 「今天」畫面（#5）

| 項目 | 規格 |
|------|------|
| 內容 | 今天要做的 Dailies（依頻率與遊戲日的星期）、所有 Habits、未完成的 To-dos |
| Daily／To-do | 點一下打勾；有迷你版時可選「只做迷你版」，也算完成 |
| Habit | ＋／－按鈕，可重複點；取消從最後一次開始 |
| 取消 | 只有尚未結算的遊戲日可以取消；已結算的不顯示取消 |
| 狀態列 | 等級、經驗、HP、金幣、各屬性經驗；旅館中顯示入住狀態 |
| 換日 | App 開著跨過換日時間時，下一次操作前先結算並提示「已經換日」 |
| 空狀態 | 今天沒有要做的 Daily 時顯示空狀態文案（依設計稿） |

### F4 數值循環（#6）

| 項目 | 規格 |
|------|------|
| 完成獎勵 | 依難度給金幣、經驗、屬性經驗；職業主屬性的屬性經驗乘以設定檔倍率 |
| 迷你版 | 獎勵乘以設定檔的迷你版比例 |
| Habit「－」 | 依難度扣 HP |
| 日結 | 未完成的 Daily 依難度扣 HP；完成的 streak + 1 |
| HP 歸零 | 依決策表的懲罰規則 |
| 等級 | 由累計經驗與等級曲線算出 |
| 所有數字 | 來自 `src/config/balance.json`，對應決策表 |

### F5 旅館（#7）

入住後，日結不扣血、Daily 不計、streak 不變；可隨時退房。當天入住當天就生效（`day-rollover.md` 第 3.3 節）。

### F6 預設庫（#8）

依屬性（體能／智慧／心靈／連結／財務）與類型（Habits／Dailies／To-dos／獎勵）分類；每項顯示名稱、迷你版、難度、屬性；點「＋」加入，已加入的顯示標記（可重複加入，名稱相同時不阻擋）。

### F7 進階編輯（#9）

可改：名稱、備註、迷你版、難度、屬性、標籤、頻率（每天／平日／週末／自訂星期）、檢查清單；可刪除（軟刪除）。修改頻率以結算當下為準（`day-rollover.md` 第 5.12 節）。刪除任務**不收回**已經拿到的金幣、經驗與屬性經驗（事件只新增不修改；與 Habitica 一致，2026-10-24 tech-lead 決定）。來源標示：任務的 `sourceTemplateId` 屬於目前職業套組且建立於選職業當天時顯示「來自職業套組」，否則有來源模板時顯示「來自預設庫」。

### F8 自訂獎勵（#10）

預設三項來自內容資料包，可新增、編輯、刪除；金幣足夠才能兌換（金幣不足時按鈕停用）；當天可取消兌換。

### F9 匯出／匯入（#11）

設定頁可下載 JSON 備份；匯入時驗證格式、自動備份目前資料、舊版先遷移、新版拒絕；失敗時原資料不變（`data-model.md` 第 8 節）。

### F10 設定與紀錄

換日時間（下一個遊戲日生效）、旅館、是否顯示財務屬性、最近事件紀錄（筆數依設定檔）、版本號、匯出／匯入。

### F11 快速新增（#12，P2）

輸入文字，依內容資料包的關鍵字判斷類型、屬性、預設難度；判斷不到時讓使用者手動選。時間不夠可整項砍掉。

## 驗收標準

依提案書第 9 節：

- [ ] iPhone 加入主畫面後全螢幕開啟，飛航模式下可正常打卡
- [ ] 從安裝到完成第一次打卡 ≤ 60 秒（含選職業）
- [ ] 四個職業各自帶入正確的預設套組
- [ ] 打勾、取消後，金幣／經驗／屬性經驗正確增減
- [ ] 日結：未完成 Daily 正確扣血；旅館期間不扣血；多日未開補算符合決策表
- [ ] 預設庫一鍵加入、進階編輯可用
- [ ] 匯出 → 清除資料 → 匯入後狀態完全還原
- [ ] 換日與數值邏輯單元測試全數通過

## Sprint 2：RPG 包裝（第一章：被窩史萊姆）

> 版本: v2.0 | 最後更新: 2026-11-12 | 作者: product-manager
> 來源：`proposal/sprint2-proposal.md`（第 2、6、9 節、第 12 節老闆決策）、`proposal/sprint2-dev-plan.md`（第 1 節 G1 決定、第 6 節任務 T1～T29、第 8 節）、`.knowledge/data-model.md` 第 12 節（v2）、`.knowledge/decision-tables.md` 第 14 節（v1.1／v1.2／v1.2.1）、`docs/design/mockup-s2-*.html`、`docs/content/sprint2-story-draft.md`（v0.2）、`.knowledge/specs/api-design.md`（推播 API）
> 規則：**本章不寫任何遊戲數值**，一律寫「決策表 14.x 的哪個欄位」；數字只在決策表與 `balance.json`／內容資料包。任務 ID 為 Sprint 2 的 T1～T29（`.tasks/sprint-2/`），提到 Sprint 1 任務寫「S1 TN」。
> 圖稿狀態編號簡寫：battle ＝ `mockup-s2-battle.html`、story ＝ `mockup-s2-story.html`、reminder ＝ `mockup-s2-reminder.html`、quickadd ＝ `mockup-s2-quickadd.html`、sprites ＝ `mockup-s2-sprites.html`。

### 概述

Sprint 2 讓打卡「看得到敵人、打得到敵人」：打開 App 就是第一人稱戰鬥畫面（G1 方案 A），被窩史萊姆在正前方；打勾＝攻擊，漏掉的每日討伐＝隔天的反擊（沿用 Sprint 1 日結扣血，只改呈現）。新玩家選職業後、既有玩家升級後各看一次序章，接著進第一章；打倒被窩史萊姆後進入「和平的森林＋第二章敬請期待」（D3）。另有隨機事件（旅途奇遇、世界狀態）、劇情播放、每日推播、快速新增圖稿對齊（B4）、像素字型（B1）、戰士／法師外觀與職業圖示（B2）。

Sprint 1 的 F1～F11 規則全部沿用；本章只寫新增與變更。不做的項目見提案書第 2 節「不做」。

### 詳細規格

#### F14 劇情播放與跳過確認（提案 #4；T15）

| 項目 | 規格 |
|------|------|
| 對話框 | 全螢幕；說話者名牌＋頭像；旁白無名牌、無頭像（story ⑥-2） |
| 逐字 | 速度讀決策表 14.13.1 `story.charsPerSecond`（v1.2.1）；尚未跳出的字保留位置、框不跳動（story ①） |

| 減少動態 | `prefers-reduced-motion` 開啟時整段直接出現（決策表 14.13.1 規則） |
| 跳過 | 右上「跳過 ▶▶」→ **二次確認**（G1 #5；story ④）；確認後直接進第一章戰鬥畫面；跳過也算看過（`seenScenes.skipped = true`） |

| 播放中 | 不能打勾 |
| 劇情種類 | 序章（new／returning）、職業一句、章節標題卡（story ⑤）、Boss 登場（story ⑥）、Boss 血量階段台詞（決策表 14.13.1 `phases`，每階段只播一次，14.13.3 #9）、擊敗（story ⑦）、通關卡（story ⑧） |

#### F16 打勾傷害與取消（提案 #2；T8、T11、T14）

| 項目 | 規格 |
|------|------|
| 哪些有傷害 | Daily 打勾、To-do 完成、Habit「＋」（D2）；Habit「－」不影響 Boss（決策表 14.2 規則表） |
| 傷害量 | 公式與速查表：決策表 14.2（`difficulties.<key>.bossDamage`、`battle.taskTypeDamageMultiplier`、`battle.miniDamageRatio`、世界狀態 `bossDamageMultiplier`）；實際傷害不超過 Boss 目前 HP，記在打卡事件 `payload.bossDamage` |
| Habit「＋」超過上限 | 超過 `habitUp.maxRewardedPerDay` 的那幾次無傷害（14.2） |
| 職業 | 不加成傷害（14.2） |
| 畫面 | 傷害數字跳出、HP 條減少（白色段＝剛打掉）、訊息框（battle ③；文案劇情草稿 3.1～3.6） |
| 取消 | Boss HP 加回原事件記下的傷害，不重算；金幣、經驗照 Sprint 1 退回；畫面綠色數字（battle ④） |
| 不造成傷害的情況 | 旅館期間（14.2、14.4）、擊敗後（14.2）、序章看完前（14.13.3 #8） |
| 血量階段 | Boss HP 第一次跌破 `phases[].hpPercent` 時播該階段台詞一次（14.13.1、14.13.3 #9） |

#### F17 擊敗確定制（提案 #2；T8、T11、T14、T15）

| 項目 | 規格 |
|------|------|
| 擊敗 | 讓 Boss HP 到 0 的那次打卡（或奇遇）**當下**寫 `boss_defeated`（不可取消），播擊敗演出（battle ⑩）→ 擊敗對話（story ⑥-2、⑦）→ 通關卡（story ⑧）→ 和平的森林（F19）（決策表 14.5） |
| 擊敗後取消 | 那次及之後的打卡仍可取消：金幣、經驗、HP 照 Sprint 1 退回；**不退 Boss 傷害、Boss 不復活**，顯示提示（battle ⑩-2；文案劇情草稿 3.11） |
| `maxHp` 被下修到低於累計傷害 | 下次打開 App 判定擊敗，照常播擊敗＋通關；未播的血量階段台詞不補播（14.13.3 #6） |

#### F18 日結反擊與多日摘要（提案 #2、#3；T9、T11、T14）
