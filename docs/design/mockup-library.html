本頁不適用的狀態

  • 已結算不可取消：不適用。預設庫只做「加入」，不產生打卡事件，沒有可取消的東西；要移除已加入的項目請到進階編輯刪除（軟刪除）。
  • 旅館中：不適用。旅館只影響換日結算（不扣 HP、每日討伐不計），不影響加入；本頁不顯示旅館標記。
  • HP 低：不適用。HP 只影響「今天」頁的警示，預設庫內容與操作不變。

假設與待 G1 確認

  • 企劃書 3.1 的項目屬於哪一類型沒寫；圖稿假設 3.1 列的都是每日討伐，Habit 的屬性（例如「－吃宵夜」算體能）也是假設。
