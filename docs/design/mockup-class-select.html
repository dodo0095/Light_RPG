本頁不適用的狀態

  • 空狀態：不適用。四個職業固定來自內容資料包 class_sets；資料包讀不到屬於 App 啟動錯誤（data-model 5：設定檔讀不到就顯示錯誤），不是本頁的空狀態。「未選」時套組區塊的提示即本頁的空白樣子（①）。
  • 已完成：不適用。建立成功後直接進入「今天」，本頁不再出現（feature-spec F2）。
  • 已結算不可取消：不適用。選職業前沒有任何打卡紀錄；選職業時 lastSettledDayKey 設為前一天（day-rollover 5.11）。
  • 旅館中：不適用。角色還沒建立，沒有旅館狀態。
  • HP 低：不適用。角色建立時 HP 為上限，本頁不顯示 HP。
