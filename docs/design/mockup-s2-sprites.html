實作備註

  • 像素圖一律 image-rendering: pixelated、整數倍放大；Retina 下以 CSS px 計的 3×／4× 已足夠清楚，不需另出 2x 圖。
  • 造型資料（格子、調色盤）建議跟職業一起放進內容資料包或 src/render/ 的資料檔，不寫死在元件（CLAUDE.md 規則 3，#9 職業圖示同理）。
  • 描邊色 #1a1530 統一，避免不同角色看起來像不同遊戲。
  • 背景用 Bayer 4×4 抖色，放大後仍是像素感；若改成預先輸出的 PNG，單張約 2～5 KB。
