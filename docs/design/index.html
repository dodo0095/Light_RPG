晨光之誓・Sprint 1 圖稿

G1 送審稿 v0.1（2026-10-23，ui-designer，受 design-director 委派）。四頁 HTML mockup，以 iPhone 直式 390px 為基準，每頁以並排手機框靜態呈現所有狀態。

  • 字型：標題／數值 DotGothic16（Google Fonts），內文系統字型 -apple-system, "PingFang TC", "Noto Sans TC"。DotGothic16 缺的繁體字會自動退回系統字型；正式版改用俐方體 11 號（企劃書 7.1）時只需改 --font-pixel。
  • 安全區域：--safe-top／bottom／left／right 預設取 env(safe-area-inset-*)；圖稿手機框內覆寫成 47px／34px 並以粉紅虛線示意。實作需在 index.html 的 viewport 保留 viewport-fit=cover（目前已有）。
  • 觸控目標：所有按鈕、勾選框、晶片、分頁最小 44×44px（--touch）。檢查清單子項的小勾選框是整列可點（列高 44px）。
  • 建議 theme-color 改為 #0a1030（--c-bg）；目前 index.html 暫定 #1a2b4c，改不改由實作決定，需同步 vite.config.ts。
  • tokens.css 最後一節 .mk-* 只給圖稿用（手機框、標註），實作時不要搬進 src/。
