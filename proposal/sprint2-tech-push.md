## 背景

iPhone 的網頁推播（Web Push）必須由伺服器送出，App 自己沒辦法在關閉時跳通知。老闆決定用部署機（已經在跑 `deploy/serve.mjs`＋Caddy）送推播，伺服器有開才送。

這是本專案第一次讓伺服器保存資料，所以要先講清楚：**伺服器存什麼、不存什麼、怎麼部署**。

### 前提（iPhone 的限制）

- iOS 16.4 以上，而且 App 必須從**主畫面**開啟（Safari 分頁收不到推播）
- 要使用者在 App 內**點按鈕**才能請求通知權限（不能自動跳）
- 推播送到 Apple 的推播伺服器，再轉給 iPhone；部署機需要能連外網（已具備）

## 選項比較

| 面向 | A. 併入 serve.mjs（建議） | B. 獨立推播服務 | C. 不寫伺服器，用 iPhone「捷徑」提醒 |
|------|--------|--------|--------|
| 描述 | 現有 `serve.mjs` 加 `/api/push/*` 端點與每日排程，同一個程式、同一個 port | 另開一個 Node 程式（另一個 port），Caddy 把 `/api/push/*` 轉過去 | 教老闆在「捷徑」App 設個人自動化，每天定時跳提醒 |
| 優點 | 部署步驟不變（同一個 `node deploy\serve.mjs`、同一個開機自動啟動）；Caddy 設定不用改；同網域，CSP `connect-src 'self'` 不用改 | 推播壞掉不影響網頁；職責分開 | 不用寫程式、沒有伺服器資料 |
| 缺點 | 推播程式出錯可能拖垮網頁伺服器（用 try/catch 與獨立模組隔離） | 要多一個開機自動啟動、多改一段 Caddy 設定，部署機維護變複雜 | 只有老闆自己能用，試用的其他人要各自設定；提醒不是 App 發的，無法連到遊戲內容 |
| 成本 | 約 1.5～2 天（伺服器端＋App 設定頁＋Service Worker 推播處理＋測試） | 約 2～2.5 天 | 約 0.5 天（寫教學文件） |

## 建議

**選 A**，細節如下：

| 項目 | 做法 |
|------|------|
| 伺服器存的資料 | 只有「推播訂閱」（Apple 給的推播網址與加密金鑰）＋「每天提醒時間」。**不存任何遊戲資料**（角色、任務、打卡都還是只在 iPhone）。存在部署機的 JSON 檔（`deploy/data/`，不進版控） |
| 推播內容 | 固定文案，例如「被窩史萊姆還在等你，今天的冒險開始了嗎？」。伺服器不知道你今天打卡了沒，所以每天都會提醒 |
| 提醒時間 | 使用者在設定頁選（預設 08:00，台灣時間）；伺服器每分鐘檢查一次，時間到就送 |
| 伺服器沒開的時候 | 那天就不送，開機後也不補送（「有開才送」） |
| 推播金鑰（VAPID） | 在部署機產生一次，放環境變數（`.env`，不進版控）；**私鑰不寫進程式碼** |
| 防濫用 | 訂閱端點限制每分鐘次數（API 規範：一般公開 API 60 次／分）、請求大小上限、訂閱總數上限（例如 20 個）；失效的訂閱自動刪除 |
| App 端 | 設定頁新增「每日提醒」：開關＋時間；開啟時才請求通知權限。伺服器連不上時顯示「伺服器沒開，暫時無法設定提醒」，**其他功能完全不受影響**（離線照常打卡） |
| Service Worker | 目前用 vite-plugin-pwa 自動產生的 SW，不能處理推播事件；要改成自訂 SW（`injectManifest` 模式）加上推播處理。這會動到更新機制，需重新驗證「有新版本，點此更新」 |
| 新套件 | 伺服器端加 `web-push`（處理推播加密的標準套件）。`serve.mjs` 目前零依賴，這是第一個；鎖版本並寫進 `deploy/README.md` |

### 之後可以再加（本 Sprint 不做）

- App 打完當天的勾時告訴伺服器「今天已完成」，伺服器就不送提醒。這會讓伺服器知道一點點遊玩狀態，等試用回饋再決定。

## 影響

1. **`CLAUDE.md` 規則 1 要改**：從「沒有後端」改為「遊戲資料不上伺服器；唯一例外是部署機的推播服務，只存推播訂閱與提醒時間」
2. **部署機**：要多放一個 `.env`（推播金鑰），第一次要跑一個產生金鑰的指令；之後更新流程不變
3. **Service Worker 改為自訂**：Sprint 2 實作與實機驗收要包含「更新提示」回歸測試
4. **隱私**：推播網址由 Apple 產生，不含姓名或帳號；伺服器不存遊戲資料
5. **`.knowledge/architecture.md`** 第 4 節要補推播架構圖；`deploy/README.md` 要補金鑰設定步驟
